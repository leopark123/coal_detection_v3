# 开发计划（煤检测项目）

## 1. 项目目标

1. 在模拟开发阶段完成稳定检测闭环（手动照片输入 + 可回归测试）。
2. 在测试稳定后，再进入生产链路开发（真实相机/PLC/部署流程）。
3. 建立可交接、可追溯、可回滚的协作机制。

## 2. 阶段划分

## Phase-0：交接与质量底座（已进入）

- 目标:
  - 统一交接材料
  - 收敛重复逻辑
  - 稳定测试回归
- 完成标准:
  - `handoff/` 文档齐全
  - 全量测试稳定通过
  - 关键流程有证据路径

## Phase-1：模拟链路稳定化（当前主线）

- 目标:
  - 完成模拟数据源下的业务稳定性验证
  - 固化 Web 实时推流、检测状态、异常处理
- 完成标准:
  - 模拟链路核心场景可重复执行
  - 回归测试持续通过
  - 已知高优先问题进入可控状态

## Phase-2：生产链路开发（门禁后开启）

- 前置门禁:
  - Phase-1 验证通过
  - 用户确认进入生产链路
- 目标:
  - 接入真实相机驱动
  - 接入 PLC 写入链路
  - 完成生产运行与故障回退流程
- 完成标准:
  - 生产链路端到端可演示
  - 关键指标达标并有验收证据

## Phase-3：上线准备与验收

- 目标:
  - 完成部署、回滚、运维文档
  - 完成最终验收
- 完成标准:
  - 发布/回滚脚本可执行
  - 验收表闭环

## 3. 里程碑

1. M0: 交接包建立并可用（已完成）
2. M1: 模拟链路回归稳定（进行中）
3. M2: 生产链路接入完成（未开始）
4. M3: 上线验收完成（未开始）

## 4. 当前风险

- 真实账号/设备未完全接入，生产链路验证暂不可做。
- 现阶段样本以手动照片为主，覆盖度需持续扩充。
- Windows 环境存在部分临时目录权限限制，需要继续规避。
