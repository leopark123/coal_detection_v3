# 建议补充表清单

以下表单用于降低换 AI/换人后的信息损失。

| 表名 | 作用 | 当前状态 |
|---|---|---|
| 决策记录表(ADR) | 记录关键技术/业务决策及理由 | 已创建：`handoff/决策记录表_ADR.csv` |
| 变更日志表 | 记录需求和范围变化 | 已创建：`handoff/变更日志表.csv` |
| 缺陷跟踪表 | 管理BUG生命周期 | 已创建：`handoff/缺陷跟踪表.csv` |
| 测试与验收表 | 形成验收证据 | 已创建：`handoff/测试与验收表.csv` |
| 接口契约表 | 固化模块边界 | 已创建：`handoff/接口契约表.csv` |
| 数据集与标注表 | 保证识别迭代可复现 | 已创建：`handoff/数据集与标注表.csv` |

## 优先级建议

1. 第一优先：ADR、缺陷、测试与验收
2. 第二优先：接口契约、变更日志
3. 第三优先：数据集与标注（随识别迭代持续更新）
