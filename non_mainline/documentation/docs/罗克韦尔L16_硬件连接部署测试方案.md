# 罗克韦尔 L16 + Windows 工控机 + acA1600-60gm 测试硬件、连接与部署方案

> **注意**：本文档部分 IP 地址和参数已更新为实际部署值（2026-03）。

## 1. 文档目的

本文档用于明确当前阶段系统测试所需的硬件组成、网络连接方式、部署方式和测试前置条件，确保现有软件系统能够在一套最小可用现场环境中完成联调、功能验证和初步稳定性验证。

当前方案面向测试环境，不是最终正式投产方案。测试环境以一台 Windows 电脑作为临时服务器，完成视觉算法运行、相机采集、PLC 通信、Web 页面展示和日志留存。

## 2. 当前测试目标

本阶段目标如下：

- 验证工业相机采图链路可稳定运行。
- 验证 Windows 电脑可作为临时视觉服务器运行检测软件。
- 验证电脑与罗克韦尔 PLC L16 之间以太网通信正常。
- 验证检测结果、心跳、故障码、系统就绪状态可正确写入 PLC。
- 验证 Web 页面可在局域网内访问，用于查看检测画面和运行状态。
- 为后续生产部署提供硬件和网络基线。

## 3. 测试环境硬件组成

本次测试环境硬件建议如下：

### 3.1 核心设备

- PLC：罗克韦尔 L16
- 工业相机：acA1600-60gm，Mono8 灰度 GigE 相机（IP: 192.168.1.12）
- 视觉服务器：1 台 Windows 电脑，临时承担算法服务、Web 服务和日志存储
- 交换设备：1 台千兆工业交换机或千兆办公交换机
- 网线：不少于 3 根 Cat5e 或 Cat6 屏蔽网线
- 显示器、键鼠：用于本地调试和部署

### 3.2 建议附属设备

- UPS 不间断电源 1 套，用于防止测试阶段突然断电
- 独立网卡 1 块，如果 Windows 电脑已有双网口则可不额外增加
- 相机镜头、安装支架、补光灯，根据现场成像条件选配

## 4. 硬件职责划分

### 4.1 Windows 电脑职责

- 运行视觉检测主程序
- 运行 Web 服务
- 连接工业相机并采集图像
- 通过以太网与 PLC L16 通信
- 保存日志、报警图像和运行记录

### 4.2 PLC 职责

- 接收视觉系统写入的检测结果
- 接收视觉系统心跳
- 接收系统故障码和就绪状态
- 为后续联锁或现场控制逻辑预留接口

### 4.3 相机职责

- 稳定输出彩色图像
- 通过 GigE 网络将图像传入 Windows 电脑
- 配合固定曝光、固定增益和固定安装方式完成稳定采图

## 5. 网络与连接方案

### 5.1 推荐连接拓扑

推荐采用星型网络，所有设备都接入同一台千兆交换机。

- Windows 电脑网口 1 -> 千兆交换机
- PLC L16 以太网口 -> 千兆交换机
- acA1600-60gm 相机 -> 千兆交换机

如果 Windows 电脑具备双网口，也可采用分网方案：

- 网口 1：PLC 通信网段
- 网口 2：工业相机采集网段

如果当前只有单网口，测试阶段可先使用同一交换机、同一网段运行。

### 5.2 测试阶段推荐 IP 规划

以下为建议值，可根据现场网段调整：

- Windows 工控机：192.168.1.10
- PLC 1769-L16ER/B：192.168.1.19
- 相机 acA1600-60gm：192.168.1.12
- 子网掩码：255.255.255.0
- 网关：测试阶段可留空，或统一填写 192.168.1.1

### 5.3 连接要求

- PLC、相机、Windows 电脑必须在同一二层网络内。
- Windows 防火墙需要放通测试程序、Web 端口和 PLC 通信。
- 相机必须固定 IP，避免 DHCP 导致设备地址漂移。
- PLC 和相机建议都使用静态 IP。
- 测试阶段应避免办公网广播风暴和大流量业务与相机图像流混跑。

## 6. Windows 电脑最低建议配置

为满足当前软件测试要求，建议 Windows 电脑配置不低于以下标准：

- 操作系统：Windows 10 或 Windows 11 64 位
- CPU：Intel i5 / i7 或同等级 AMD 处理器
- 内存：16 GB 及以上，建议 32 GB
- 硬盘：至少预留 100 GB 可用空间，建议 SSD
- 网卡：千兆网卡
- Python：3.10 及以上

如果现场仅做功能验证，16 GB 内存可先使用；如果要长时间运行并保留较多报警图像和日志，建议 32 GB 内存和 SSD。

## 7. 软件部署方案

### 7.1 Windows 电脑部署内容

Windows 电脑上需要部署以下内容：

- Python 运行环境
- 项目源代码
- 依赖库
- 相机厂商 SDK
- PLC 通信依赖库
- Web 服务运行环境

### 7.2 建议安装项

- Python 3.10 或以上
- 项目 `requirements.txt` 中的依赖
- 罗克韦尔 PLC 通信库 `pycomm3`
- 相机 SDK
  - 如果 acA1600-60gm 为 Basler 设备，则建议安装 `pylon` SDK 和 Python 封装 `pypylon`
- OpenCV 运行依赖

### 7.3 目录建议

Windows 电脑建议采用如下目录结构：

- 项目目录：`D:\coal_detection_project\`
- 运行日志：`D:\coal_detection_project\logs\`
- 报警图像：`D:\coal_detection_project\logs\images\`
- 配置文件：`D:\coal_detection_project\config\`

## 8. 部署步骤

### 8.1 硬件部署步骤

1. 将 PLC L16、工业相机、Windows 电脑连接到同一台千兆交换机。
2. 给 PLC、相机、Windows 电脑配置静态 IP。
3. 检查三者物理链路灯是否正常。
4. 在 Windows 电脑上分别 `ping` PLC 与相机 IP。
5. 固定相机安装位置、镜头焦距和拍摄区域。
6. 若现场光照不稳定，增加补光并固定照明条件。

### 8.2 软件部署步骤

1. 在 Windows 电脑安装 Python。
2. 安装项目依赖。
3. 安装 PLC 通信库和相机 SDK。
4. 将项目部署到固定目录。
5. 根据实际 IP 修改配置文件。
6. 先使用开发模式和 Mock 验证主程序可启动。
7. 再切换至真实 PLC 和真实相机模式进行联调。

### 8.3 联调顺序

推荐按以下顺序联调：

1. 电脑网络连通性测试
2. PLC 通信单独测试
3. 相机采图单独测试
4. 主程序单机运行测试
5. 主程序与 PLC 联合测试
6. Web 页面查看测试
7. 连续稳定运行测试

## 9. 测试要求对应关系

为了满足当前软件测试要求，硬件和连接必须满足以下条件：

### 9.1 相机侧要求

- 可以稳定输出图像
- 图像分辨率与软件配置一致
- 图像采集延时可接受
- 连续运行过程中不频繁掉线

### 9.2 PLC 侧要求

- 可以通过以太网稳定连接
- 可以持续接收检测结果
- 可以接收心跳并用于存活判断
- 通信异常时可以从故障码识别视觉系统状态

### 9.3 服务器侧要求

- 能稳定运行主程序与 Web 服务
- 能保存日志与报警图片
- 能支撑连续测试不少于 4 小时
- 能在局域网内提供浏览器访问

## 10. 推荐测试内容

### 10.1 基础连接测试

- PLC `ping` 测试
- 相机 `ping` 测试
- PLC 读写单点测试
- 相机连续抓图测试

### 10.2 功能测试

- 正常画面检测结果写入 PLC
- 异常画面时故障码写入 PLC
- 心跳持续递增
- Web 页面实时显示检测画面
- 报警图片正常落盘

### 10.3 稳定性测试

- 连续运行 4 小时
- 观察是否掉线、卡死、内存持续增长
- 观察日志是否出现大量超时、重连、采图失败
- 观察 PLC 是否连续收到心跳

## 11. 当前阶段建议的运行模式

考虑当前阶段是测试联调，建议分为两个阶段：

### 阶段 A：基础联调

- 相机连接真实设备
- PLC 连接真实设备
- Windows 电脑本地启动主程序
- 局域网内通过浏览器查看 Web 页面
- 重点验证网络连通、采图、PLC 写入和心跳

### 阶段 B：稳定性测试

- 保持相同硬件连接结构
- 连续运行不少于 4 小时
- 开启日志与报警图像保存
- 统计 PLC 写入异常、相机掉线、程序异常退出情况

## 12. 风险与注意事项

- 当前 Windows 电脑是临时服务器，测试可用，但生产环境仍建议使用专用工控机或专用服务器。
- 相机 SDK 和 Python 依赖必须与实际相机型号匹配，否则无法切换到真实采图。
- PLC tag 名称、数据类型和程序中的写入逻辑必须完全一致，否则联调会出现“通信成功但控制无响应”的假象。
- 测试阶段日志和图片可能增长较快，应提前预留磁盘空间。
- 如果 PLC 和相机共用一个网卡，测试阶段问题不大，但后续正式部署更建议分网或 VLAN 隔离。

## 13. 建议补充的现场参数

在正式开始联调前，建议补齐以下信息：

- PLC L16 的实际 IP 地址
- PLC tag 清单及数据类型

- 相机 SDK 厂商名称与版本

- Windows 电脑型号、CPU、内存、网卡数量
- Web 页面访问端口和访问终端数量

## 14. 结论

基于当前已知条件，采用“罗克韦尔 L16 + acA1600-60gm + Windows 电脑临时服务器 + 千兆交换机”的方案，可以满足现阶段软件联调和测试需求。

建议优先完成以下三项：

- 确认 PLC 点位表
- 确认相机 SDK 与驱动安装方案
- 按固定 IP 方式完成 PLC、相机和 Windows 电脑的网络配置

完成上述内容后，即可进入现场硬件联调和软件部署测试阶段。
