## 转换为Word文档的方法

### 方法1: 使用 Pandoc（推荐）

**安装Pandoc**:
1. 访问 https://pandoc.org/installing.html
2. 下载并安装Windows版本
3. 确认安装：在命令行输入 `pandoc --version`

**执行转换**:
```cmd
# 直接运行转换脚本
convert_to_word.bat
```

**或手动执行**:
```cmd
# 转换迁移方案
pandoc "docs\迁移方案详细文档.md" -o "docs\翻车机积煤检测系统V3.0-迁移方案.docx" --toc

# 转换架构设计
pandoc "docs\系统架构设计文档.md" -o "docs\翻车机积煤检测系统V3.0-架构设计.docx" --toc
```

### 方法2: 使用 Python脚本

**安装依赖**:
```cmd
pip install python-docx markdown beautifulsoup4 lxml
```

**执行转换**:
```cmd
python convert_to_word.py
```

### 方法3: 在线转换工具

1. **Pandoc Try**: https://pandoc.org/try/
   - 复制Markdown内容
   - 选择输出格式为docx
   - 下载生成的Word文档

2. **Word Online**:
   - 新建Word文档
   - 复制Markdown内容到Word
   - 手动调整格式

### 方法4: 直接在Word中导入

1. 打开Microsoft Word
2. 文件 → 打开 → 选择Markdown文件
3. Word会自动转换格式
4. 手动调整样式和布局
