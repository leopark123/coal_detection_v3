# 高级柔性网格标定工具使用说明

## 工具概述

为了处理复杂的现场情况（遮挡、异形、变形格栅），我们开发了高级柔性网格标定系统：

### 适用场景
- ✅ 格栅有部分区域被遮挡（横梁、电机等）
- ✅ 格栅形状不规则或有变形
- ✅ 相机角度造成透视畸变
- ✅ 需要精确标定每个格子位置

## 三步标定流程

### Step 1: 外部形状定义 (ROI Mask)
**目的**: 圈出可见区域，排除遮挡物和黑边

**操作**:
1. 用鼠标依次点击，绘制可见区域的多边形边界
2. 尽量贴近格栅边缘，避开遮挡物
3. 按 `SPACE` 键完成多边形绘制
4. 按 `r` 键可以重新绘制

### Step 2: 逻辑拓扑定义 (Logical Grid)
**目的**: 设置格栅的理论行列数

**操作**:
1. 在终端输入格栅的理论总行数（如：8）
2. 输入格栅的理论总列数（如：8）
3. 程序会在ROI区域内生成初始均匀网格

**注意**: 即使有些格子被遮挡看不到，也要输入完整的理论尺寸

### Step 3: 柔性网格精调 (Mesh Editing)
**目的**: 拖拽调整网格节点，精确贴合真实格栅

**操作**:
- **拖拽节点**: 鼠标左键拖动绿色节点，调整网格形状
- **整体移动**: `Shift + 鼠标拖动` 可移动整个网格
- **保存配置**: 按 `s` 键保存标定结果
- **重置网格**: 按 `r` 键重置为均匀网格
- **退出工具**: 按 `q` 键退出

**颜色说明**:
- 🟢 绿色格子：有效区域（在ROI内）
- ⚫ 灰色格子：无效区域（被遮挡或在ROI外）
- 🟢 绿色节点：可拖拽的控制点
- 🟡 黄色节点：鼠标悬停状态
- 🔴 红色节点：当前选中拖拽状态

## 使用方法

### 1. 运行标定工具

```bash
# 对干净格栅图片进行标定
python tools/advanced_calibrator.py tests/mock_data/clean/2.png --output config/grid_advanced.json
```

### 2. 使用标定结果进行检测

```bash
# 使用标定配置检测积煤
python tools/advanced_detector.py tests/mock_data/clean/2.png --config config/grid_advanced.json --save-result logs/advanced_result.jpg
```

## 输出配置格式

标定完成后会生成 JSON 配置文件，包含：

```json
{
  "source_image": "tests/mock_data/clean/2.png",
  "calibration_method": "advanced_flexible",
  "mask_polygon": [[x1,y1], [x2,y2], ...],    // ROI多边形
  "logic_shape": [8, 8],                       // 理论行列
  "mesh_points": [[[x,y],...], ...],           // 所有网格节点
  "total_theoretical": 64,                     // 理论总格子数
  "valid_cells": [                             // 有效格子列表
    {
      "id": 0,
      "row": 0,
      "col": 0,
      "points": [[x1,y1], [x2,y2], [x3,y3], [x4,y4]], // 四边形角点
      "area": 1234.5
    }
  ],
  "valid_count": 45                            // 实际有效格子数
}
```

## 优势特点

1. **所见即所得**: 设备挡住的区域直接排除，不参与检测
2. **逻辑自洽**: 保持格子的行列拓扑关系，便于系统管理
3. **极致精准**: 支持不规则四边形，完美适应现场变形
4. **智能过滤**: 自动识别有效/无效区域，提高检测准确性

## 检测原理

检测器基于**结构可见性分析**：
- **高结构分数**: 纹理丰富、边缘清晰、梯度强烈 → 格栅可见
- **低结构分数**: 纹理平坦、边缘模糊、梯度弱 → 被积煤覆盖

相比传统的亮度判断，结构分析更准确、抗干扰能力更强。

## 下一步工作流程

1. **用户标定**: 使用标定工具精确标定一张干净格栅图片
2. **算法优化**: 根据标定结果调优检测参数
3. **效果验证**: 用同一位置的不同积煤状态图片验证检测效果
4. **参数调优**: 根据检测结果微调阈值和算法参数
