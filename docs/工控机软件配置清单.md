# 翻车机积煤检测系统 - 工控机软件配置清单

## 1. 操作系统要求
- **Windows 10 Professional 64位** 或 **Windows 11 Professional 64位**
- 至少 8GB 内存，推荐 16GB
- 至少 100GB 可用磁盘空间
- 支持千兆以太网

## 2. 基础软件环境

### Python 3.10+
```powershell
# 下载地址：https://www.python.org/downloads/
# 安装时勾选 "Add Python to PATH"
python --version  # 验证安装
```

### Microsoft Visual C++ Redistributable
```
下载 Microsoft Visual C++ 2015-2022 Redistributable (x64)
https://aka.ms/vs/17/release/vc_redist.x64.exe
```

## 3. 工业相机软件

### Basler Pylon SDK
```
下载地址：https://www.baslerweb.com/en/software/pylon/
版本要求：Pylon 7.4.0 或更高版本

安装组件：
✅ Pylon Runtime
✅ Pylon Viewer (相机测试工具)
✅ Pylon API (Python 支持)
✅ GigE Vision SDK
```

**安装后验证：**
1. 运行 Pylon Viewer
2. 检测 Basler 相机连接
3. 测试图像采集功能

## 4. PLC通信软件

### RSLogix 5000/Studio 5000
```
✅ 已安装 RSLogix 5000
版本要求：v32.00 或更高版本

确保安装了以下组件：
✅ RSLogix 5000 Logix Designer
✅ RSLinx Classic
✅ FactoryTalk Services Platform
```

**网络配置：**
- 在 RSLinx Classic 中添加 Ethernet/IP 驱动
- 配置 PLC 通信路径

## 5. Python 依赖库

### 创建安装脚本

将以下内容保存为 `install_dependencies.bat`：

```batch
@echo off
echo 安装翻车机检测系统依赖...

:: 升级 pip
python -m pip install --upgrade pip

:: 核心依赖
pip install numpy>=1.24.0
pip install opencv-python>=4.8.0
pip install loguru>=0.7.0
pip install PyYAML>=6.0

:: Web 界面
pip install fastapi>=0.100.0
pip install uvicorn>=0.23.0
pip install python-multipart>=0.0.6
pip install jinja2>=3.1.0

:: 硬件驱动
pip install pypylon>=3.0.0
pip install pycomm3>=1.2.0

:: 测试工具
pip install pytest>=7.0.0
pip install psutil>=5.9.0

echo 依赖安装完成！
pause
```

## 6. 网络配置

### 网卡设置（静态IP）
```
IP地址：192.168.1.10
子网掩码：255.255.255.0
网关：192.168.1.1
DNS：8.8.8.8 (可选)
```

### 防火墙配置
```powershell
# 允许 Python 程序通过防火墙
# 允许端口 8000 (Web界面)
# 允许端口 44818 (Ethernet/IP)
```

## 7. 目录结构准备

在工控机上创建以下目录：
```
C:\CoalDetection\
├── logs\                # 日志文件
├── logs\images\         # 报警图像存档
├── config\              # 配置文件
└── backup\              # 配置备份
```

## 8. 系统服务配置（可选）

### 创建 Windows 服务
可以将检测系统配置为 Windows 服务，开机自启动：

```batch
# 使用 NSSM (Non-Sucking Service Manager)
# 下载：https://nssm.cc/download
nssm install CoalDetection "C:\Python310\python.exe" "C:\CoalDetection\main.py"
```

## 9. 安全配置

### 用户权限
- 创建专用服务账户：CoalDetectionService
- 赋予网络访问权限
- 赋予日志目录写入权限

### 系统优化
```
1. 禁用 Windows 更新自动重启
2. 设置高性能电源模式
3. 禁用不必要的后台服务
4. 配置定时重启计划（可选）
```

## 10. 验证清单

完成安装后，运行以下验证：

```batch
# Python 环境验证
python --version
python -c "import cv2, numpy, loguru; print('核心库OK')"

# 硬件驱动验证
python -c "import pypylon; print('Basler驱动OK')"
python -c "import pycomm3; print('PLC驱动OK')"

# 网络连通性验证
ping 192.168.1.100  # 相机
ping 192.168.1.200  # PLC
```
