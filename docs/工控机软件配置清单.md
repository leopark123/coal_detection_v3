# 翻车机积煤检测系统 - 工控机软件配置清单

## 1. 操作系统要求
- **Windows 10 Professional 64位** 或 **Windows 11 Professional 64位**
- 至少 8GB 内存，推荐 16GB
- 至少 100GB 可用磁盘空间
- 支持千兆以太网

## 2. 基础软件环境

### Python 3.10+
```powershell
# 下载地址：https://www.python.org/downloads/
# 安装时勾选 "Add Python to PATH"
python --version  # 验证安装
```

### Microsoft Visual C++ Redistributable
```
下载 Microsoft Visual C++ 2015-2022 Redistributable (x64)
https://aka.ms/vs/17/release/vc_redist.x64.exe
```

## 3. 工业相机软件

### Basler Pylon SDK
```
下载地址：https://www.baslerweb.com/en/software/pylon/
版本要求：Pylon 7.4.0 或更高版本

安装组件：
✅ Pylon Runtime
✅ Pylon Viewer (相机测试工具)
✅ Pylon API (Python 支持)
✅ GigE Vision SDK
```

**安装后验证：**
1. 运行 Pylon Viewer
2. 检测 Basler acA1600-60gm 相机连接（IP: 192.168.1.12）
3. 测试图像采集（1600×1200, Mono8）

## 4. PLC 通信软件

### RSLogix 5000 / Studio 5000
```
✅ 已安装 RSLogix 5000
版本要求：v32.00 或更高版本

确保安装了以下组件：
✅ RSLogix 5000 Logix Designer
✅ RSLinx Classic
✅ FactoryTalk Services Platform
```

**网络配置：**
- 在 RSLinx Classic 中添加 Ethernet/IP 驱动
- 浏览到 PLC: 192.168.1.19
- 确认 PLC 型号：1769-L16ER/B B1B，固件 36.11

## 5. Python 依赖库

### 创建安装脚本

将以下内容保存为 `install_dependencies.bat`：

```batch
@echo off
echo 安装翻车机检测系统依赖...

:: 升级 pip
python -m pip install --upgrade pip

:: 核心依赖
pip install numpy>=1.24.0
pip install opencv-python>=4.8.0
pip install loguru>=0.7.0
pip install PyYAML>=6.0

:: Web 界面
pip install fastapi>=0.100.0
pip install uvicorn>=0.23.0
pip install python-multipart>=0.0.6
pip install jinja2>=3.1.0
pip install websockets>=12.0

:: 硬件驱动
pip install pypylon>=3.0.0

:: 测试和监控
pip install pytest>=7.0.0
pip install psutil>=5.9.0

```

## 6. 网络配置

### 网卡设置（静态 IP）

| 设备 | IP 地址 | 说明 |
|------|---------|------|
| 工控机 | 192.168.1.10 | 本机 |
| 相机 | 192.168.1.12 | Basler acA1600-60gm (GigE) |
| PLC | 192.168.1.19 | AB 1769-L16ER/B B1B |

```
工控机网卡：
  IP地址：192.168.1.10
  子网掩码：255.255.255.0
  网关：192.168.1.1（可选）
```

### 防火墙配置
```powershell
# 允许 Python 程序通过防火墙
netsh advfirewall firewall add rule name="Python" dir=in action=allow program="C:\Python310\python.exe"

# 允许 Web 界面端口
netsh advfirewall firewall add rule name="CoalDetection Web" dir=in action=allow protocol=tcp localport=8080

# 允许 Ethernet/IP (PLC 通信)
netsh advfirewall firewall add rule name="EthernetIP" dir=in action=allow protocol=tcp localport=44818

# 允许 GigE Vision (相机)
netsh advfirewall firewall add rule name="GigE Vision" dir=in action=allow protocol=udp localport=3956
```

## 8. 启动方式

```powershell
# 生产模式（连接真实硬件）
cd D:\coal_detection_project
python -m uvicorn web.unified_app:app --host 0.0.0.0 --port 8080

# 开发模式（无硬件）
set COAL_ENV=DEV
python -m uvicorn web.unified_app:app --host 0.0.0.0 --port 8080

# 浏览器访问
# http://localhost:8080
```

## 9. 系统服务配置（可选）

### 创建 Windows 服务
```batch
# 使用 NSSM (Non-Sucking Service Manager)
# 下载：https://nssm.cc/download
nssm install CoalDetection "C:\Python310\python.exe" "-m" "uvicorn" "web.unified_app:app" "--host" "0.0.0.0" "--port" "8080"
nssm set CoalDetection AppDirectory "D:\coal_detection_project"
```

## 10. 系统优化

```
1. 禁用 Windows 更新自动重启
2. 设置高性能电源模式
3. 禁用不必要的后台服务
4. 配置 Jumbo Frame（GigE 相机性能优化）
5. 相机网卡 MTU 设为 9000（如交换机支持）
```
