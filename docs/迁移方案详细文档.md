## 1. 项目概述

### 1.1 系统简介
翻车机积煤检测系统V3.0是一套基于计算机视觉的工业安全监控系统，用于实时检测翻车机格栅上的积煤情况，防止煤炭堆积导致的设备故障和安全事故。

### 1.2 技术特点
- **实时性**: 端到端延迟 < 100ms
- **安全性**: 宁可漏报，不可误报的设计原则
- **可靠性**: 双缓冲架构，采集永不停机
- **智能性**: 三级置信度判定，多帧投票机制
- **灵活性**: 开发模式与生产模式无缝切换

### 1.3 关键性能指标

| 指标 | 要求 | 说明 |
|------|------|------|
| 单帧处理延迟 | ≤ 80ms | 从读取帧到输出结果 |
| 端到端延迟 | ≤ 150ms | 从采集到PLC写入完成 |
| 跳帧率 | ≤ 10% | 超过说明算法需要优化 |
| 心跳间隔 | 500ms ± 50ms | PLC校验用 |

## 7. 安全规范

### 7.1 工业安全要求

#### 7.1.1 安全红线
> ⚠️ **本系统直接关联翻车机安全连锁，任何改动都要考虑"如果这里出错，翻车机会怎样"**

| 安全原则 | 说明 | 技术实现 |
|---------|------|----------|
| 宁可漏报，不可误报 | 误报积煤→翻车机急停→设备损坏 | 严格的阈值设置，多帧投票 |
| 采集永不停 | 采集进程永不阻塞 | 双缓冲架构，异步处理 |
| 心跳必须有 | 500ms心跳递增 | 定时器+计数器 |
| 故障必须报 | 所有异常都要上报 | 完整的故障码系统 |

#### 7.1.2 故障码定义
```python
FAULT_NONE = 0           # 正常运行
FAULT_CAMERA_FAIL = 1    # 相机故障
FAULT_PLC_COMM = 2       # PLC通信故障
FAULT_QUALITY_FAIL = 3   # 画面质量问题
FAULT_LOW_CONFIDENCE = 4 # 低置信度，需人工确认
```

### 7.2 网络安全

#### 7.2.1 网络隔离
- **工业网络**: 独立的工业以太网，与办公网物理隔离
- **防火墙**: 配置严格的访问控制规则

- **密码策略**: 强密码要求，定期更换

### 7.3 数据安全

#### 7.3.1 备份策略
- **配置备份**: 每次修改配置后自动备份
- **数据备份**: 重要检测数据定期备份
