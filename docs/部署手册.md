## 1. 系统概述

### 功能

实时检测翻车机格栅积煤状态，通过视觉算法判定是否可以翻车，结果写入 PLC 安全连锁信号。

### 核心链路

```
Basler 相机（GigE）
    → 图像采集（5.5 FPS，1600×1200，Mono8→BGR）
    → 质量自检 → ECC 配准 → CLAHE 增强
    → 格栅孔计数 + 积煤面积检测
    → 多帧投票判定（采集窗口内）
    → Allen Bradley PLC 写回（Vision_CanTip 等安全标签）
    → Web 界面实时展示
```

| 2# 翻车机 | machine-2 | 192.168.1.20 | 1 | 192.168.1.18 |

## 3. 工控机环境准备

### 3.1 操作系统

- Windows 10 / Windows 11（64 位）
- 建议关闭 Windows 自动更新（防止重启中断服务）

### 3.2 网卡配置

1. 打开「网络和共享中心」→「更改适配器设置」
2. 右键连接交换机的网卡 → 属性 → IPv4
3. 设置：
   - IP 地址：`192.168.1.10`
   - 子网掩码：`255.255.255.0`
   - 默认网关：留空（工业隔离网络）

### 3.3 Basler Pylon SDK 安装

1. 下载地址：https://www.baslerweb.com/downloads/software/
2. 选择 **Pylon Camera Software Suite** for Windows（版本 ≥ 7.0）
3. 安装时勾选 **GigE 相机支持**
4. 安装完成后，打开 **pylon Viewer** 验证能否发现相机

> **注意**：安装 Pylon SDK 后，pypylon 才能正常工作。

### 3.4 Python 安装

1. 下载 Python 3.10 或 3.11（64 位）：https://python.org/downloads/
2. 安装时勾选 **Add Python to PATH**
3. 验证：
   ```powershell
   python --version
   # 应输出 Python 3.10.x 或 3.11.x
   ```

## 5. 拓扑配置

编辑 `config\devices.yaml`，按实际现场设备填写：

```yaml
machines:
- id: machine-1
  name: 9#翻车机
  plc_ip: 192.168.1.19        # PLC IP 地址
  plc_timeout_ms: 3000
  plc_heartbeat_interval_ms: 500
  funnels:
  - id: funnel-1
    name: 1#漏斗
    camera_ip: 192.168.1.12   # 相机 IP 地址
    pixel_format: mono         # Basler acA1600-60gm 灰度相机填 mono
    camera_timeout_ms: 5000
    grid_count: 125            # 格栅口总数
    grid_config_path: config/grid_manual.yaml  # 格栅标定文件
    capture_cycle_s: 30.0      # 两次采集最短间隔（秒）
    capture_window_s: 3.0      # 单次采集窗口时长（秒）
    capture_delay_s: 2.0       # PLC 触发后的预热延迟（秒）
    capture_vote_threshold: 0.6  # 多帧投票阈值（60% 帧报警才输出报警）
  # ... 其余漏斗同上

- id: machine-2
  name: 2#翻车机
  plc_ip: 192.168.1.20
  plc_timeout_ms: 3000
  plc_heartbeat_interval_ms: 500
  funnels:
  - id: funnel-2
    name: 2#漏斗
    camera_ip: 192.168.1.18
    pixel_format: mono
    camera_timeout_ms: 5000
    grid_count: 125
    grid_config_path: config/grid_manual.yaml
    capture_cycle_s: 30.0
    capture_window_s: 3.0
    capture_delay_s: 2.0
    capture_vote_threshold: 0.6
```

> **注意**：`config\devices.yaml` 会被运行时的管理界面写回，每次通过 Web 管理页面增删漏斗后该文件都会更新。如需还原，用 `git checkout -- config/devices.yaml`。

### 算法参数说明（`config/config.py` 默认值）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `GRID_VISIBLE_THRESHOLD` | 0.85 | 格栅可见率阈值，低于此值视为画质异常 |
| `COAL_COVERAGE_THRESHOLD` | 0.05 | 积煤面积阈值 |
| `VOTE_WINDOW_SIZE` | 5 | 多帧投票窗口帧数 |
| `VOTE_THRESHOLD` | 3 | 投票通过所需最少报警帧数 |

## 7. 启动服务

双击运行 `start_production.bat`，或在 PowerShell 中：

```powershell
cd "D:\coal_detection_project 1"
```

## 9. Web 界面使用说明

访问地址：**http://192.168.1.10:8080**（从其他机器访问用工控机 IP）

| 页面 | 地址 | 功能 |

## 10. 运行状态监控

### 10.1 实时日志

服务运行时日志直接输出到控制台，同时写入 `logs\` 目录。

### 10.2 长时稳定性监控

```powershell
cd "D:\coal_detection_project 1"
.\start_monitor.bat
```

每 30 秒输出一次系统指标（内存、相机帧率、PLC 心跳、WebSocket 连接数），结果保存到 `logs\monitor_report.json`。

### 10.3 关键健康指标

| 指标 | 正常范围 | 异常处理 |
|------|---------|---------|
| PLC 心跳 | 每 500ms 递增 | 检查网络/PLC 状态 |
| 相机帧率 | ~5.5 FPS | 检查网线、交换机流量 |
| 单帧检测延迟 | ≤ 80ms | 检查 CPU 占用 |
| 跳帧率 | ≤ 10% | 优化检测参数或升级硬件 |

### 10.4 PLC 标签说明

| 标签名 | 类型 | 方向 | 说明 |
|--------|------|------|------|
| `Vision_CanTip` | BOOL | 服务器→PLC | **安全连锁核心**：True=可翻车 |
| `Vision_FaultCode` | DINT | 服务器→PLC | 0=正常，1=相机故障，2=PLC通信，3=画质，4=低置信度 |
| `Vision_ResultValid` | BOOL | 服务器→PLC | True=结果可信（高/中置信度） |
| `IPC_Heartbeat` | DINT | 服务器→PLC | 每 500ms 递增，PLC 用于判活 |
| `IPC_Online` | BOOL | 服务器→PLC | True=视觉系统在线 |
| `PLC_CaptureCmd` | DINT | PLC→服务器 | 1=开始采集指令 |
| `Vision_CaptureState` | DINT | 服务器→PLC | 0=空闲，1=采集中，2=判定完成 |

**采集时序**：

```
PLC_CaptureCmd=1
    → 服务器开始采集，Vision_CaptureState=1
    → 采集窗口到时（3秒），判定完成
    → 服务器写结果 + Vision_CaptureState=2
    → PLC 读到 State=2，复位 PLC_CaptureCmd=0
    → 服务器读到 Cmd=0，Vision_CaptureState=0，回到空闲
```

## 11. 故障排查

### 相机连接失败

**现象**：日志出现 `BaslerCamera 连接失败`，漏斗页面显示红色

**排查步骤**：
1. 打开 Pylon Viewer，检查能否发现相机
2. 检查网线是否插好，交换机指示灯是否亮绿
3. 确认工控机 IP 与相机在同一子网（192.168.1.x）
4. 确认无其他程序（如另一个 pylon Viewer）占用相机
5. 若相机 IP 不对，通过 Pylon IP Configurator 重新设置

> **自愈机制**：服务启动时相机未上线，系统会每 60 秒自动重试重连，无需重启服务。

### PLC 通信失败

**现象**：日志出现 `AllenBradleyPLC 连接失败`，PLC 状态显示离线

**排查步骤**：
1. 检查 PLC 是否上电，网线是否连接
2. 在工控机上 ping PLC IP：`ping 192.168.1.19`
3. 确认 PLC 程序中 EtherNet/IP 通信模块已启用
4. 检查 PLC 防火墙设置（端口 44818）

### 检测结果始终低置信度

**现象**：`Vision_FaultCode=4`，频繁需要人工确认

**排查步骤**：
1. 检查相机画面是否清晰，光照是否足够
2. 检查格栅标定文件 `config/grid_manual.yaml` 是否匹配当前安装位置
3. 在设置页面适当调整 `GRID_VISIBLE_THRESHOLD`（降低）或 `COAL_COVERAGE_THRESHOLD`（调整）

### 画质自检失败（fault_code=3）

**现象**：`Vision_FaultCode=3`，`Vision_CanTip=False`

**可能原因**：
- 镜头污染、积灰遮挡
- 光照不足或过曝
- 大量格栅不可见（可见率 < 85%），系统判定画质异常

**处理**：清洁镜头，检查补光灯，重新标定格栅 ROI。

### 服务启动后自动退出

**排查步骤**：
1. 查看 `logs\watchdog.log`（`start_production.bat` 会写入退出记录）
2. 查看控制台最后的错误信息
3. 常见原因：端口 8080 已被占用（`netstat -ano | findstr 8080`）
